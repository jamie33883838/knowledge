# 肝纖維化非侵入性評估

不需肝切片即可評估肝纖維化程度的工具集合，可替代大多數臨床情境下的肝切片。

## 為何需要非侵入性評估？

- 肝切片有風險（出血、感染）、取樣誤差、觀察者間差異
- 需反覆監測疾病進展時，侵入性工具不適合作為篩查工具

## 主要工具比較

### 血清指數

| 工具 | 組成 | 晚期纖維化 AUROC | 特點 |
|------|------|-----------------|------|
| **APRI** | AST、血小板 | 0.568–0.803 | 計算簡單，常用於 HCV、HBV |
| **[[FIB-4指數]]** | 年齡、AST、ALT、血小板 | 0.802–0.896 | 整體優於 APRI，最廣泛使用 |
| FibroTest / FibroSURE | 5 血清標記 + 年齡性別 | 0.75–0.86 | 需商業檢驗，多種肝病均有驗證 |
| ELF test | 3 直接纖維化標記（HA、TIMP-1、PIIINP） | 0.75–0.85 | 直接反映纖維化本身 |

### 影像工具

- **瞬態彈性超音波（FibroScan）**：最廣泛使用的非侵入性彈性評估
- **磁振彈性成像（MRE）**：精確度更高，適合困難病例
- **剪切波超音波（SWE）**：可於超音波檢查時同步進行

## 臨床決策流程

```
第一步：FIB-4 初篩
  ↓ FIB-4 < 1.3 → 排除晚期纖維化（NPV 90%）→ 定期追蹤
  ↓ FIB-4 > 3.25 → 確認晚期纖維化（特異性 97%）→ 轉介 / 治療
  ↓ FIB-4 1.3–3.25（不確定）
      ↓
第二步：ELF test 或彈性超音波 進一步評估
      ↓ 仍不確定
第三步：肝切片（此時才考慮）
```

## 注意事項

- **FIB-4 限制**：35 歲以下或 65 歲以上可靠性下降（65 歲以上建議改用 FIB-4 cutoff 2.0）
- **FibroTest 禁忌**：Gilbert syndrome、溶血、膽道阻塞、急性肝炎時會高估纖維化
- **MASLD 中的 FIB-4**：對極瘦或極肥胖（BMI Class III）患者效果較差
