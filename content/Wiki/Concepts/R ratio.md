# R ratio

量化肝損傷模式（肝細胞型 vs 膽汁淤積型 vs 混合型）的計算公式，最初用於藥物性肝損傷（DILI）的評估。

## 公式

```
R = (ALT實測值 / ALT正常上限) ÷ (Alkaline Phosphatase實測值 / ALP正常上限)
```

## 解讀

| R 值 | 損傷模式 |
|------|---------|
| > 5 | 肝細胞型（[[肝細胞損傷模式]]） |
| 2–5 | 混合型 |
| < 2 | 膽汁淤積型（[[膽汁淤積模式]]） |

## 臨床應用

- 最初用於 DILI 的損傷分型
- 對嚴重 DILI 有**高特異性和高陰性預測值**（陽性結果仍需結合臨床判斷）
- 肝細胞型損傷且 R 值高 → 死亡或需肝移植風險更高

## 混合型損傷的常見原因

- 藥物性肝損傷（DILI）
- 酒精性肝炎
- 急性病毒性肝炎（CMV、EBV）
- 肝外膽道阻塞
- 自體免疫重疊症候群
