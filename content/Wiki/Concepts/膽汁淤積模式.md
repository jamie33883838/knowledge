# 膽汁淤積模式（Cholestatic Pattern）

Alkaline Phosphatase 和 Bilirubin 升高為主，反映膽汁流出受阻（可為肝內或肝外原因）。

## 判斷標準

- [[R ratio]] < 2 → 膽汁淤積型損傷
- Alkaline Phosphatase 顯著升高，ALT/AST 相對輕度或正常
- 確認肝臟來源：合併 GGT 或 5'-nucleotidase 升高

## Alkaline Phosphatase 的來源鑑別

Alkaline Phosphatase 並非肝臟專一，需排除非肝臟來源：

| 來源 | 特點 |
|------|------|
| 肝臟（膽汁淤積） | 合併 GGT 或 5'-nucleotidase 升高 |
| 骨骼 | GGT 正常，bone ALP isoenzyme 升高（骨折、Paget 病、骨軟化症） |
| 胎盤 | 懷孕第二至三學期生理性升高，可達 2×ULN |
| 小腸 | 少見 |

## 病因分類

**肝外膽道阻塞（緊急排除）**
- 膽管結石、膽管炎 → 急性症狀合併 ALP 升高需立即評估
- 膽管狹窄、惡性腫瘤壓迫

**肝內膽汁淤積（慢性）**
- 原發性膽汁性膽管炎（PBC）：IgM 升高，AMA 陽性
- 原發性硬化性膽管炎（PSC）：常合併 IBD
- 藥物（Amoxicillin-clavulanate、合成類固醇等）

**遺傳性膽汁淤積（兒童為主）**
- 進行性家族性肝內膽汁淤積（PFIC）：基因突變導致
