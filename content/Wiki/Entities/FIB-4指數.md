# FIB-4 指數（Fibrosis-4 Index）

> 類型：計算型生化指標

評估肝纖維化嚴重程度的非侵入性評分，使用常規抽血數據計算，是目前臨床最廣泛使用的肝纖維化篩查工具。

## 計算公式

```
FIB-4 = (年齡 × AST) / (血小板數 × √ALT)

單位：年齡（歲），AST（U/L），血小板（10⁹/L），ALT（U/L）
```

## 臨床解讀

| FIB-4 值 | 意義 | NPV / 特異性 |
|----------|------|-------------|
| < 1.3 | 排除晚期纖維化 | NPV 90%（強陰性預測值） |
| 1.3–3.25 | 不確定，需進一步評估 | — |
| > 3.25 | 確認晚期纖維化 | 特異性 97% |

**65 歲以上患者建議使用修正 cutoff：> 2.0 排除晚期纖維化**

## 適用疾病

已在以下疾病中驗證：
- 慢性 HCV 感染（AUROC 0.896）
- 慢性 HBV 感染（AUROC 0.8165）
- MASLD（AUROC 0.802）
- ALD

## 與 APRI 比較

| 比較項目 | FIB-4 | APRI |
|---------|-------|------|
| 組成 | 年齡、AST、ALT、血小板 | AST、血小板 |
| AUROC（HCV 晚期纖維化） | 0.896 | 0.823 |
| AUROC（MASLD 晚期纖維化） | 0.802 | 0.568–0.803 |
| 建議 | **首選** | 備選 |

## 注意事項

- **35 歲以下**：年齡因子可能低估纖維化風險
- **65 歲以上**：年齡因子可能高估，使用 FIB-4 > 2.0 替代 > 3.25
- **MASLD 中的限制**：對極瘦（lean MASLD）或 Class III 肥胖者效果較差

## 在臨床流程中的位置

FIB-4 是[[肝纖維化非侵入性評估]]的**第一步篩查工具**：

```
FIB-4 < 1.3 → 定期追蹤
FIB-4 > 3.25 → 轉介/治療
FIB-4 1.3–3.25 → 彈性超音波或 ELF test 進一步評估
```
